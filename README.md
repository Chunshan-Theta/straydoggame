# 浪浪收容所（straydoggame）

單頁（`index.html`）的 4 人同機輪流桌遊試玩版：1 位政府玩家 + 3 位收容所玩家，共 5 回合。直接以瀏覽器開啟 `index.html` 即可遊玩，進度自動存在瀏覽器 localStorage。

## 流程
- 每回合依序：收容所 1 → 收容所 2 → 收容所 3 → 政府「協調環節」。
- 每位玩家行動次數不限，完成後按「結束回合／交棒」；政府確認後回合結算。
- 每回合開始時街頭新增 2 隻浪浪（受事件卡影響）。

## 資金
- 政府開局 $30，之後依協調環節規則補充；收容所開局 $0。
- 沒有飼料、醫療包與聲望，所有行動直接扣／加資金。

## 收容所行動
| 行動 | 費用 | 說明 |
|---|---|---|
| 收容浪浪 | $1 | 受容量限制（基礎 3 隻，每座設施 +1） |
| 治療病犬 | $2 | 醫療站每座 -$1（最低 $0）；獎勵 $1，每座醫療站再 +$1 |
| 訓練凶犬 | $2 | 訓犬基地每座 -$1（最低 $0）；獎勵 $1，第 2 座起每座再 +$1 |
| 募款宣傳 | 免費 | +$3，每回合限一次 |
| 興建設施 | 見下表 | 每座 +1 容量與對應管道 +1 送養額度，數量不限 |

## 設施
| 設施 | 成本 | 效果 |
|---|---|---|
| 咖啡廳 | $2 | 每回合 +$1；每座 1 個咖啡廳送養額度（一般浪浪，+$2） |
| 訓犬基地 | $1 | 降低訓練費；每座 1 個訓練所送養額度（訓練過的凶犬，+$1） |
| 醫療站 | $1 | 降低治療費；每座 1 個醫療所送養額度（治癒的病犬，+$1） |

## 送養
- 各送養管道的每回合額度獨立計算，設施數量不限：
  - 基本送養：固定 1 隻，一般浪浪 +$1。
  - 咖啡廳：每座 1 隻，一般浪浪 +$2。
  - 醫療站：每座 1 隻，只能送養治癒的病犬，+$1。
  - 訓犬基地：每座 1 隻，只能送養訓練過的凶犬，+$1。
- 每次成功送養政府公共信任 +1。

## 政府協調環節
- 在所有收容所行動結束後，政府可支援特定收容所：出資蓋設施、給予經費，或兩者並行，並提案讓該收容所收容一隻未安置的街頭浪浪（不得超過容量）。可進行多次。
- 每次支援公共信任 +1。
- 回合結算時依未安置浪浪數量補充政府預算：少於 3 隻 +$5；3–4 隻 +$3；5–6 隻 +$1；7 隻以上無。

## 事件、危機與結束條件
- 每回合一張事件卡（連日大雨、公益領養日、企業公益募款、巡迴醫療日、社區絕育合作）。
- 政府確認後，依街頭未安置浪浪數量翻危機卡並立即結算：1–2 隻翻 1 張、3–4 隻翻 2 張、5–6 隻翻 3 張、7 隻以上翻 4 張；0 隻不翻。
- 街頭浪浪超過 8 隻（≥ 9）：遊戲立即結束。
- 收容所有收容犬時，每回合結束照護分 +1。
- 5 回合結束後計分。

## 計分
- 收容所：送養數 ×3 + 照護分 + 設施數 ×2 + 健康犬 − 病犬 − 凶犬（收容中）。
- 政府：公共信任 + 政策介入次數 + 全體成功送養數。
