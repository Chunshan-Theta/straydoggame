# 浪浪收容所（straydoggame）

單頁（`index.html`）的 4 人桌遊試玩版：1 位政府玩家 + 3 位收容所玩家，共 5 回合。直接以瀏覽器開啟 `index.html` 即可遊玩，進度自動存在瀏覽器 `localStorage`。

## 遊戲模式（支援 NPC 模式）
- **角色選擇**：玩家進入遊戲時，可自由選擇扮演「政府」或「收容所」。
- **NPC 系統**：支援同機輪流或單人遊玩。未由真人扮演的角色（政府，或一至多家收容所）可交由 NPC 接管；NPC 會根據**期望值**與**機構關係好感度**自動進行收容、建設與談判決策。

## 流程
- 每回合依序：政府補助環節 -> 收容所 1 → 收容所 2 → 收容所 3 → 政府「協調環節」 → 回合結算（自動送養 → 餵食 → 預算與危機卡）。
- 收容所完成行動後按「結束回合／交棒」；政府於協調環節完成談判並確認後，依序進行自動送養、餵食視覺化結算、預算補充與危機卡結算。
- 政府開局 $30，收容所開局 $0。沒有飼料、醫療包、聲望、募資與事件卡，所有行動直接扣／加資金。

## 收容所行動
1. **安置流浪動物（必做、免費）**：
   - 輪到收容所時抽 1 隻流浪動物，須處理完才能進行其他行動，這個行動必須執行兩次。
   - **效果盲抽**：收容前**不顯示**動物的特殊效果（避免玩家依效果挑選），確認安置後才會揭曉並觸發效果；不安置或無法安置則進入流浪區。
   - **空間與設施限制**：安置時須具備足夠收容空間；若為病犬或凶犬，收容所當下必須已具備對應的「醫療所」或「訓犬基地」空間才可收容，**不可先收容再補蓋設施，如果空間不夠必須立即支付建造費用才可收容**。
2. **治療病犬（選擇性）**：$2，需至少一座醫療所；每座醫療所每回合可治療 1 隻，無立即獎勵（治癒後可於結算階段自動送養）。
3. **訓練凶犬（選擇性）**：$2，需至少一座訓犬基地；每座每回合可訓練 1 隻，無立即獎勵（訓練後可於結算階段自動送養）。
4. **興建設施**：見下表，數量不限（收容所於自身回合自費興建；政府出資協建僅限於「政府協調環節」進行）。

動物特殊效果：明星犬（安置者 +$2）、媒體焦點（政府預算 +$2）、帶著小狗（免費再帶回一隻流浪區動物，需有空間）。

## 設施
每座新設施 基礎容量為1,送養額度1, 送養時獎勵為+1，各設施獨立計算。

| 設施 | 成本 | 效果 |
|---|---|---|
| 收容基地 | $0(不需建造不可新建 開局每個收容所都有) | 送養時獎勵為 +$1；基礎容量為3,送養額度1 |
| 咖啡廳 | $2 | 送養時獎勵為 +$2；+1 咖啡廳送養額度 |
| 訓犬基地 | $1 | 送養時獎勵為+1 訓練所送養額度；+1 每回合訓練額度 |
| 醫療所 | $1 | 送養時獎勵為+1 醫療所送養額度；+1 每回合治療額度 |

## 送養（餵食前系統自動執行）
於政府協調環節結束後、**餵食結算之前**，由系統依各收容所可用額度**自動送養**符合條件的動物並發放獎勵：

| 管道 | 額度 | 對象 | 獎勵 |
|---|---|---|---|
| 基本 | 1 | 一般浪浪 | +$1 |
| 咖啡廳 | 每座 1 | 一般浪浪 | +$2 |
| 醫療所 | 每座 1 | 已治癒的病犬（只能從醫療所送養） | +$1 |
| 訓犬基地 | 每座 1 | 已訓練的凶犬（只能從訓練所送養） | +$1 |

## 政府協調環節與回合結算
- **協調與補助談判**：
  - 流浪區的動物在此階段會**公開展示其特殊效果**。
  - 政府**僅能在此環節**出資幫指定收容所蓋設施、給予額外經費，或兩者並行（包含在協調條件中）。
  - 政府針對流浪區動物提出補助條件後，**依序向收容所詢問是否收養**（當超過該所容量及對應設施限制，政府必須出資幫忙新建設施），收容所可選擇**「要」**或**「不要」**。談判可進行多次。
- **協調完畢後結算**（依序執行）：
  1. **自動送養**：於餵食前，由系統自動送養所有符合資格與額度的收容動物。
  2. **餵食（視覺化結算）**：每隻留在收容所的動物每回合需 $1 伙食費。結算畫面須明確顯示**各收容所支付多少伙食費**、**資金不足差額多少**，以及**導致多少隻安置犬退回流浪區**。
  3. **政府預算**：待未餵食動物退回流浪區後，依當前流浪動物數補充：少於 3 隻 +$5；3–4 隻 +$3；5–6 隻 +$1；7 隻以上 +$0。
  4. **危機卡**：餵食與退回結算完畢後，說明並翻開對應數量的危機卡：0 隻不翻；1–2 隻翻 1 張；3–4 隻翻 2 張；5–6 隻翻 3 張；7 隻以上翻 4 張。

## 結束與計分
- 流浪動物超過 8 隻（≥ 9）：遊戲立即結束。
- 5 回合結束後，以手上資金計分，資金最多者獲勝（政府亦以預算計），若流浪區不為空則全員失敗。
